Práce s reporty

📋 Panel reportu v aplikaci

Report panel se nachází v pravém panelu aplikace (záložka Report) a umožňuje sběr a správu nálezů během analýzy videa.

Funkce panelu:
+
Tlačítko "+" (Přidat)

Přidá aktuální snímek videa do reportu včetně času a vybrané sekvence

📤
Tlačítko "Export"

Otevře report v novém okně jako HTML stránku připravenou k tisku nebo uložení

🗑️
Tlačítko "Vymazat"

Vymaže všechny položky reportu (používejte opatrně!)

📸 Jednotlivé položky reportu

Každá položka v reportu obsahuje následující informace:

Automaticky zachycené údaje:
  • • Název sekvence - identifikátor kamery
  • • Globální čas - přesná časová značka
  • • Video soubor - název zdrojového videa
  • • Čas ve videu - lokální čas v rámci videa
  • • Náhled snímku - automatický screenshot
Uživatelská nastavení:
  • • Checkbox "Bounding box" - zobrazí/skryje detekované objekty
  • • Textové pole "Komentář" - vlastní poznámky
  • • Výběr položky - kliknutím skočíte na daný čas
  • • Kontextové menu - pravé tlačítko pro smazání

➕ Jak přidat záznamy do reportu

Existují 3 způsoby přidání:

  1. Tlačítko "+" v Report panelu - přidá aktuální snímek
  2. Pravé tlačítko na časové ose → "Přidat do reportu"
  3. Kontextové menu ve výsledcích - přidá konkrétní detekci

📄 Exportovaný report

Ukázka exportovaného HTML reportu s tabulkou nálezů

Struktura exportovaného reportu (viz screenshot):
📊 Hlavička reportu:
  • • Autor: textové pole pro jméno
  • • Datum vytvoření: automaticky generované (např. 9/25/2025, 12:02:15 AM)
  • • Poznámky: textové pole pro obecné poznámky
  • • Tlačítko "Vytisknout PDF" v pravém horním rohu
📋 Tabulka s nálezy:
  • • Zdroj - celá cesta k video souboru (např. vlc-record-2024-04-09-11h17m18s-002_DALNICE.MOV-.mp4)
  • • Čas - přesná časová značka (např. 00:00:07.54)
  • • Obrázek - náhled snímku z videa
  • • Komentář - uživatelské poznámky (např. "text 1", "text 2")

💡 Tip: Report je plně interaktivní HTML stránka, kterou lze editovat před tiskem. Pole "Autor" a "poznámky" lze vyplnit přímo v exportovaném dokumentu.

📦 Export Dialog (rozšířený export výsledků)

Kromě HTML reportu nabízí AISEE rozšířený Export Dialog s mnoha možnostmi exportu dat:

Dostupné formáty exportu:
📦 ZIP archiv

Kompletní export jako ZIP soubor obsahující obrázky, metadata a volitelně video klipy

📊 CSV metadata

Export metadat v tabulkovém formátu pro zpracování v Excelu nebo jiných nástrojích

🖼️ Obrázky

Export snímků s/bez bounding boxů, volitelně v originálním rozlišení videa

🎬 Video klipy

Krátké video úseky zachycující detekce v kontextu okolních snímků

Konfigurovatelné sloupce CSV exportu:
Timestamp
Confidence
Třída (label)
FPS
SHA hash souboru
Track ID
Bounding box souřadnice
Název sekvence
Název souboru
⚠️
Limit exportu

Export je omezen na maximálně 500 položek najednou. Pro export většího množství dat použijte filtrování k rozdělení exportu na menší části.

💡 Tip: Zaškrtněte "Originální rozlišení" pro export obrázků v plném rozlišení zdrojového videa. Ve výchozím stavu se exportují zmenšené náhledy.

🖨️ HTML Report a PDF tisk

HTML Export:
  • • Otevře se v novém okně prohlížeče
  • • Plně interaktivní HTML stránka
  • • Obsahuje všechny obrázky inline
  • • Lze uložit jako HTML soubor
PDF Tisk:
  • • Tlačítko "Vytisknout PDF"
  • • Optimalizováno pro formát A4
  • • Automatické stránkování
  • • Zachovává formátování tabulky

💡 Tipy pro efektivní práci s reporty

  • ✓ Průběžné dokumentování - přidávejte nálezy hned při analýze
  • ✓ Využití komentářů - popisujte kontext a důležité detaily
  • ✓ Bounding boxy - zapněte pro zvýraznění detekovaných objektů
  • ✓ Navigace - kliknutím na položku v reportu skočíte na daný čas
  • ✓ Export - report se generuje s aktuálním tokenem pro přístup k obrázkům
