Podporované formáty

Seznam podporovaných video formátů a technické specifikace

🎥 Video formáty

  • ✓ MP4 - doporučený formát
  • ✓ MOV - Apple QuickTime
  • ✓ AVI - Windows Video
  • ✓ MKV - Matroska Video
  • ✓ WEBM - Web Media
  • ✓ MPG/MPEG - MPEG Video
  • ✓ WMV - Windows Media Video

⚙️ Technické parametry

  • •
    Rozlišení: až 4K (3840×2160)
  • •
    FPS: 1-120 snímků/s
  • •
    Kodeky: H.264, H.265/HEVC, VP8, VP9
  • •
    Maximální velikost: dle nastavení serveru
  • •
    Délka videa: bez omezení

⚠️ Důležité informace

  • •
    Automatická konverze: Systém automaticky převede videa do jednotného formátu pro optimální zpracování
  • •
    Frame Step: Vyšší hodnota = rychlejší zpracování, ale nižší přesnost detekce
  • •
    Kvalita videa: Vyšší kvalita = lepší detekce, ale delší zpracování
  • •
    Segmentovaná videa: Lze nahrát více segmentů a spojit je funkcí "Sloučit"

💡 Tipy pro optimální výsledky

  • ✓ Používejte videa s rozlišením alespoň 720p pro lepší detekci
  • ✓ Pro dlouhá videa zvažte vyšší Frame Step (např. 5)
